# 🍄 Habit Quest

A bright, retro 8-bit habit tracker. Group daily habits into weekly or monthly **Quests**, log your reps, steps and minutes, earn XP, and level up.

Built with Next.js 16, Tailwind v4, Drizzle and Neon Postgres, and deployed on Vercel.

For setup, architecture and deploy steps, see **[DEVELOPER_GUIDE.md](DEVELOPER_GUIDE.md)**.
